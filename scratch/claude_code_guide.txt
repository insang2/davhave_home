01. 클로드 코드란?
클로드 코드(Claude Code)는 Anthropic이 만든 공식 AI 코딩 어시스턴트 CLI(명령줄 도구)입니다.
터미널에서 claude 라고 입력하면 AI가 여러분의 프로젝트를 분석하고, 코드를 작성하고, 파일을 수정하고, 명령어를 실행해
줍니다. 코딩을 모르는 분도 자연어(한국어)로 지시하면 됩니다.

클로드 코드로 할 수 있는 것들은 다음과 같습니다.

예시

파일 관리

"폴더 정리해줘"

"변경사항 커밋해줘"

04. 설치하기
방법 1: 공식 설치 스크립트 (권장)
가장 간단하고 자동 업데이트가 지원되는 방법입니다.

Windows (PowerShell)

PowerShell을 관리자 권한으로 실행한 후:
irm https://claude.ai/install.ps1 | iex

Windows (CMD)
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS / Linux
터미널을 열고:

curl -fsSL https://claude.ai/install.sh | bash

안정 버전(stable)으로 설치하기

최신 버전이 불안정할 수 있으므로, 안정 버전을 원하면:
# macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash -s stable

방법 2: Homebrew (macOS / Linux)
brew install --cask claude-code

09. 자주 발생하는 문제 해결
"command not found: claude"
설치 후 claude 명령어를 못 찾는 경우, PATH 설정이 필요합니다.

Windows (PowerShell)
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin",
'User')

그 후 터미널을 껐다가 다시 열기

macOS (Zsh)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Linux (Bash)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

설치 스크립트가 HTML을 반환하는 경우
네트워크 또는 지역 문제입니다. 대안으로 설치하세요:
# macOS/Linux
brew install --cask claude-code
# Windows
winget install Anthropic.ClaudeCode

}
